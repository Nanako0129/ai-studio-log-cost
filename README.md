# Google AI Studio Log Cost

Tampermonkey userscript that shows a paid-tier Gemini API cost estimate next to token usage on Google AI Studio log and preview pages.

- Install: https://greasyfork.org/ (search "Google AI Studio Log Cost")
- Prices live in the `PRICING` table in `google-ai-studio-log-cost.user.js`; source: https://ai.google.dev/gemini-api/docs/pricing
- Greasy Fork syncs from the raw file on `main`, so bump `@version` on every change.
